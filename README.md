# 🃏 Coup

A Java implementation of the bluffing card game **Coup**, developed as a personal hobby project.

The project focuses on implementing the core game logic and rules of Coup using object-oriented programming in Java.

## 🎮 About the Project

Coup is a strategy and bluffing card game where players use character abilities, challenge other players and attempt to eliminate their opponents.

This project currently runs as a console application. It was created to practice Java development, object-oriented programming and the implementation of game logic.

## ✨ Features

- Core game logic for Coup
- Different character roles and abilities
- Player actions and interactions
- Challenge and bluffing mechanics
- Console-based gameplay

## 🛠️ Technologies

- Java
- Maven
- Git
- GitHub

## 🚀 Future Development

A possible next step is to develop the project into a web application with a graphical user interface.

This could include a Spring Boot backend and a modern frontend framework such as Vue.
